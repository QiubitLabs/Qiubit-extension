# ROLE & OBJECTIVE
You are a senior product designer + frontend engineer. Build a stunning, production-grade
MARKETING LANDING PAGE for "Qiubit Wallet" — a self-custody, multichain crypto wallet
browser extension. The page must feel like it was made by a top web3 design team (reference
quality: phantom.com, metamask.io, rainbow.me, sui.io, rabby.io). It must be beautiful,
modern, highly interactive, animation-rich, and deeply informative. This is a conversion page:
the primary goal is "Add to Chrome / Install".

# TECH STACK (STRICT)
- React + TypeScript (.tsx components only — no plain .jsx)
- Vite (or Next.js App Router if the platform defaults to it) with the /app or /src structure
- Tailwind CSS for styling + CSS variables for design tokens
- Framer Motion for all animations and scroll interactions
- lucide-react for icons
- Fully responsive (mobile-first): breakpoints at 375 / 768 / 1024 / 1440 / 1920
- Dark theme by default (this is a crypto wallet — dark luxury aesthetic)
- Clean component architecture: one component per section, in /components/sections
- No backend needed — static marketing page. Mock any data locally.

# ANIMATION & INTERACTION REQUIREMENTS
- Use Framer Motion everywhere: reveal-on-scroll (whileInView) with tasteful stagger, parallax
  on hero, count-up numbers, hover lift + glow on cards and buttons, animated gradient text,
  the scrollytelling mockup transitions, and the FAQ accordion.
- Buttons: designed hover/focus/active states (glow, slight scale, gradient shift). Never flat.
- Respect prefers-reduced-motion: gracefully disable non-essential motion.
- Custom cursor glow or spotlight-follow effect on the hero is a nice touch (optional, subtle).
- Smooth scroll behavior for nav anchors.
- Keep it performant: animate only transform/opacity, lazy-mount heavy sections, no layout thrash.

# QUALITY BAR (must-haves)
- Clear visual hierarchy through scale contrast; intentional, non-uniform spacing rhythm.
- Real depth: layering, glass, shadows, glow — not a flat page.
- Cohesive design system: consistent radii (use rounded-2xl for cards), spacing scale, and the
  cyan/indigo/violet palette used semantically.
- Every section must look believable in a real product screenshot. No lorem-ipsum-looking filler.
- Accessible: semantic HTML (header/nav/main/section/footer), aria labels, good color contrast,
  keyboard-navigable nav, focus rings.
- Ship clean, typed, well-structured .tsx components with meaningful names.

# TONE OF COPY
Confident, clear, slightly technical but friendly. Crypto-native but not hypey. Short punchy
headlines, benefit-driven subtext. Avoid jargon walls.

Deliver the full working project with all sections above, polished and animated.
